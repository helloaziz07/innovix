## 🚀 Getting Started

### Prerequisites

- Node.js `18.x` or higher
- Python `3.12` or higher
- Docker (optional for isolated environment)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/innovix-ai/innovix.git
   cd innovix
   ```

2. **Frontend Setup**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Backend Setup**
   ```bash
   cd backend
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   uvicorn app.main:app --reload
   ```

## 🏗️ System Architecture

<div align="center">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=innovix-ai&repo=innovix&theme=blue_sky" alt="Innovix Architecture" />
</div>

Innovix uses a **Decoupled Client-Server Architecture**:
- **Frontend**: A highly responsive React SPA built with TailwindCSS and Vite, communicating via REST and WebSockets.
- **Backend**: A robust FastAPI service handling AI generation (Gemini 2.0 Flash), research scraping, and data synchronization.
- **Database**: Supabase (PostgreSQL) handles real-time authentication, user states, and project caching.
